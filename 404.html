Smart Redirect Solution

This page demonstrates how to prevent the automatic addition of "index.html" to the URL when refreshing.

// JavaScript solution to prevent unwanted redirects on refresh
if (window.location.pathname.endsWith('index.html')) {
  // Replace the URL without reloading the page
  window.history.replaceState({}, '', window.location.pathname.replace('index.html', ''));
}

Try refreshing this page - notice the URL stays clean!

How It Works

The solution uses JavaScript's history.replaceState() method to clean up the URL after any redirect without causing a page reload.

This provides a better user experience by maintaining clean URLs while still allowing the initial redirect functionality.
